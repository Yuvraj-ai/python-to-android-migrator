# Python to Android Migrator

An agent skill for migrating Python applications, including Streamlit applications, into native Kotlin/Jetpack Compose Android counterparts.

The skill is deliberately interactive: it analyzes the source application first, asks the user which features to preserve/modify/remove/add/move/replace, obtains approval for consequential architecture decisions, then implements and validates the migration.

See `SKILL.md` for the entry workflow and `references/` for detailed procedures.
